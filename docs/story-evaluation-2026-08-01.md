# 첫 번째 개선 과제

## 2일차 `첫 실무 회의`를 완전한 플레이 장면으로 만든다

대상 이벤트: `anchor.day_02_practical_meeting`

기존에는 인지·현실 요약만 있었으나, 이번 수정에서 이 사건을 2일차 오전의 완전한 장면으로 전환했다.

이 과제를 가장 먼저 선택하는 이유는 다음과 같다.

1. 1일차에 억지 연애 선택지를 넣지 않는 현재 원칙을 보존한다.
2. 플레이어의 첫 의미 있는 선택을 2일차로 앞당긴다.
3. 서아의 실제 호의와 한도윤의 과해석을 동시에 보여 준다.
4. 서아·민경·유진의 업무 태도를 한 장면에서 차별화한다.
5. 2일차 회식과 이후 공략 우선 판정의 출발 상태를 만들 수 있다.

## 장면의 고정 사실

- 서아는 잘못된 슬라이드를 띄우거나 질문에 바로 답하지 못한다.
- 플레이어는 구체적인 업무 대응을 선택한다.
- 서아가 도움을 받았다면 실제로 고마움과 인간적 호의를 느낀다.
- 서아의 발표권을 존중하며 수습한 분기에서 `아까 정말 감사했습니다. 과장님이 계셔서 다행이었어요.`는 실제 발언이다.
- 동의 없이 발표를 대신한 분기에서는 제한된 업무 감사 뒤 `다음에는 제가 계속할지 먼저 물어봐 주세요.`라고 바로잡는다.
- 이 발언에는 `romance_insert`와 고유 베일 효과를 사용하지 않는다.
- 한도윤만 실제 호의에 연애 가능성을 과하게 부여한다.
- 민경은 서아의 실수가 확대되지 않게 안건을 업무 문제로 돌린다.
- 유진은 파일 버전과 교체 시각을 기록한다.
- 서아와 민경은 이 시점에 한도윤의 행동을 반복 접근이나 위험으로 판단하지 않는다.

## 플레이어 선택

첫 구현에서는 다음 네 행동을 기준으로 분기를 설계한다.

1. 서아의 당황을 먼저 인정하고 직접 이어 갈 수 있는지 묻는다.
2. 현재 확인된 문제를 화면의 파일 버전으로 한정하고 교체·재개 지점을 제안한다.
3. 서아가 계속할지 묻고 원하면 파일 교체만 맡겠다고 제안한다.
4. 서아의 대답을 기다리지 않고 발표를 대신 이어 간다.

선택 문구는 업무 행동만 설명한다. `밀기`, `당기기`, 공략 수치와 선택 방향은 플레이어에게 노출하지 않는다.

선택마다 최소 하나의 실제 차이를 만든다.

- 서아가 감정을 직접 말하고 필요한 도움을 요청하는 반응
- 민경이 사실·영향 범위·복구 순서를 즉시 받아들이는 반응
- 서아의 발표권을 보장했는지 또는 민경이 이를 되돌려 주는지
- 유진이 기록하는 파일 버전과 재개 시각
- 실제 반응 대상과 사용한 지원 화법을 남기는 후속 플래그

## 장면 구조

```text
실무 회의 시작
→ 서아의 발표 문제 발생
→ 플레이어 업무 대응 선택
→ 서아·민경·유진의 서로 다른 반응
→ 서아의 실제 감사 또는 선택에 맞는 후속 발언
→ 한도윤의 연애 가능성 과해석
→ 2일차 회식으로 이어질 상태 기록
```
