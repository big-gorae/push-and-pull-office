# 밀당 시스템 설계

> HUD, 선택 화면, 콤보 피드백과 속마음 모드 전환은 [밀당 UI/UX 설계](push-pull-ui-ux.md)에서 관리한다.

## 결론

정상적인 미연시라면 있어야 할 `호감도`를 없애고, 한도윤이 중요하게 여기는 `밀당 주도권`만 보여 준다.

플레이어는 밀기와 당기기를 이어 `콤보`를 만들고 주도권 점수를 빠르게 올린다. 화면에서는 공략에 성공하는 듯 보이지만, 같은 연속 행동은 현실에서 의심·비호감·증거 연결을 더 빠르게 악화시킨다.

```text
스토리 모드 UI:    밀당 주도권 72   COMBO x4
속마음 모드:  통제 욕구 72     통제 시도 연쇄 x4
```

이 이름의 전환이 시스템 반전의 핵심이다.

## 플레이 목표

표면 목표는 단순하다.

> 이어지는 사건에서 밀당 주도권을 높이고, 마지막 선택에서 한 사람을 고른다.

내부 캠페인의 마지막 날 장면은 점수 조건으로 잠그지 않는다. 모든 플레이어가 도달한다. 주도권과 콤보 이력은 다음을 바꾼다.

- 한도윤이 얼마나 성공을 확신하는가
- 최종 대화의 장소와 참석자
- 상대가 준비한 대응과 증거
- 회사와 동료가 이미 어디까지 움직였는가
- 어떤 엔딩으로 이어지는가

주도권 100은 표면상 최고 점수지만 실제로는 좋은 엔딩을 뜻하지 않는다.

## 화면에 보이는 정보

관계 시스템은 두 개의 값과 연속 위치를 보여 주는 리듬 게이지 하나만 표시한다.

### 밀당 주도권

히로인별로 저장되는 0~100의 메인 점수다. 상대의 마음이 아니라 한도윤이 관계의 흐름을 자신이 통제한다고 느끼는 정도다.

플레이 중에는 `밀당 주도권`, 최초 엔딩 이후에는 `통제 욕구`로 이름을 바꾼다.

### 콤보

현재 밀당이 얼마나 오래 이어졌는지 보여 주는 `x1~x5`의 순간 배수다. 별도 게이지나 상세 내역은 두지 않고 주도권 숫자 옆에만 짧게 표시한다.

### 밀기·당기기 리듬 게이지

현재 밀기·당기기 정도를 `-100~100` 내부 값으로 저장하되 숫자는 숨기고 막대 위의 위치로만 보여 준다. 사용자가 제안한 방향에 맞춰 왼쪽을 당기기, 오른쪽을 밀기로 둔다.

```text
당기기 ──────[ 적정 당기기 | 적정 밀기 ]────── 밀기
                         ●
```

- 전체 범위: `-100 당기기 ↔ 100 밀기`
- 적정 범위: `-56 ↔ 56`
- 당기기 득점선: `-32`
- 밀기 득점선: `32`
- 일반 선택 이동량: 한 번에 `8~16`, 기본값 `12`

`approach`는 표시점을 당기기 방향으로, `space`는 밀기 방향으로 조금씩 움직인다. 한 번의 선택으로 반대편 끝까지 이동하지 않는다. `literal`은 콤보를 끊고 표시점을 한 단계 중앙에 가깝게 이동시킨다.

속마음 모드에서는 양 끝 라벨을 `접근 시도 / 거리 둠`으로 교체한다.

호감도, 상대 감정 상태 판정, 예측 점수와 확신도 베팅은 사용하지 않는다.

## 기본 플레이

한 번의 밀당은 세 단계다.

1. 상대의 말과 행동을 본다.
2. 장면에 맞는 구체적인 행동을 고른다.
3. 반응을 확인하고 리듬 표시점, 콤보와 주도권 변화를 본다.

선택지는 시스템 용어보다 실제 행동으로 쓴다.

```text
짧게 답하고 업무로 돌아간다.      # space
대화를 조금 더 이어 간다.         # approach
상대가 말한 요청을 그대로 따른다. # literal
```

태그와 예상 점수는 플레이어에게 보여 주지 않는다.

## 콤보 규칙

콤보는 적정 범위 안에서 현재 활성화된 득점선을 향해 연속으로 이동할 때 이어진다.

```text
중앙
→ 당기기
→ 당기기
→ 적정 당기기 득점선 도착
→ 목표가 밀기로 전환
→ 밀기
→ 밀기
→ 적정 밀기 득점선 도착
```

첫 유효 행동이 왕복의 시작 방향을 정한다. 활성 득점선에 도착하면 `턴 보너스`를 받고 목표가 반대편 득점선으로 바뀐다. 그때부터 반대 행동을 연속으로 골라야 콤보가 계속된다.

다음 경우 콤보가 끊기거나 득점이 중단된다.

- 활성 득점선에 도착하기 전에 방향을 바꾼다.
- 득점선에 도착한 뒤에도 같은 방향으로 더 이동한다.
- 표시점이 적정 범위 `-56~56` 밖으로 나간다.
- 상대의 말을 문자 그대로 받아들이는 `literal`을 선택한다.
- 열린 사건의 마감을 넘긴다.
- 다른 히로인 사건으로 이동한다.

콤보는 히로인마다 따로 쌓지 않는다. 현재 공략 흐름에 하나만 존재하며, 다른 인물에게 이동하면 위치는 유지하되 콤보와 활성 득점선을 초기화한다.

## 점수 규칙

적정 범위 안에서 활성 득점선을 향한 이동만 주도권 점수를 만든다. 콤보가 이어질수록 획득량이 커지고, 득점선에 도착하면 턴 보너스를 더한다.

```text
이동 점수 = 장면 기본 점수 × 현재 콤보
득점선 도착 = 이동 점수 + 턴 보너스
```

예:

| 위치 변화 | 판정 | 콤보 | 주도권 획득 |
|---|---|---:|---:|
| `0 → -12` | 당기기 득점선으로 이동 | x1 | +4 |
| `-12 → -24` | 같은 방향 연속 이동 | x2 | +8 |
| `-24 → -36` | 당기기 득점선 도착 | x3 | +18 |
| `-36 → -24` | 전환 후 밀기 이동 | x4 | +16 |

x5를 최대치로 두어 점수가 무한히 커지지 않게 한다. 정확한 기본 점수는 장면 중요도에 따라 2~5 사이에서 조정한다.

적정 범위 밖에서는 주도권 점수를 주지 않는다. 중앙으로 복귀하는 행동은 위치 회복만 하고, 적정 범위에 다시 들어온 다음 행동부터 새 콤보를 시작한다.

점수는 결과 화면에서 짧게 보여 준다.

```text
밀당 성공       +4
COMBO x3       +8
주도권         64 → 76
```

## 현실 레이어의 반전

콤보는 좋은 행동의 연속이 아니라 한도윤이 상대의 모든 반응을 다음 행동의 재료로 삼고 있다는 표시다.

각 선택은 원래 장면 효과를 그대로 적용한다. 여백을 두면 당장의 의심이 조금 낮아질 수도 있다. 그러나 콤보가 이어졌다면 별도로 `반복 패턴이 인식됨` 효과를 적용한다.

- x1~x2: 개별 행동으로 받아들일 여지가 있다.
- x3: 상대가 반복 패턴을 의심하기 시작한다.
- x4: 동료와 경험을 공유하거나 기록을 남길 가능성이 커진다.
- x5: 여러 사건이 하나의 증거 흐름으로 연결될 수 있다.

따라서 화면의 콤보 배수가 커질수록 현실의 결과도 더 부정적으로 가속된다. 다만 정확한 숨은 수치 배수는 플레이어에게 보여 주지 않는다.

현재 런타임의 반복 패턴 추가 효과는 다음과 같다. 장면에 선언된 실제 행동의 `effects`를 먼저 적용한 뒤 별도로 합산한다.

| 콤보 | 의심도 | 비호감 | 증거 |
|---:|---:|---:|---:|
| x1~x2 | 추가 없음 | 추가 없음 | 추가 없음 |
| x3 | `+3` | 추가 없음 | 추가 없음 |
| x4 | `+5` | `+2` | 추가 없음 |
| x5 | `+7` | `+4` | 반대편 득점선 도착 시 `+1` |

이 수치는 밸런싱 기준값이며 스토리 모드 UI에는 노출하지 않는다.

`literal`은 상대가 명시적인 요청이나 거절을 했을 때만 등장한다. 콤보와 표면 점수를 포기하고 그 말을 그대로 따르므로 한도윤은 이를 연애를 모르는 행동이라고 비난하지만, 현실에서는 반복 패턴을 더 만들지 않는다. 객관적인 행동이 `space`와 같다면 별도의 `literal` 선택지를 중복해서 만들지 않는다.

의심도가 내려가더라도 이미 오른 비호감도가 자동으로 내려가지는 않는다.

## 언제 밀고 언제 당기는가

플레이어는 세 가지만 본다.

### 현재 위치와 활성 득점선

표시점이 중앙에 있고 당기기 득점선이 활성화되어 있다면 당기기를 몇 번 이어 간다. 적정 당기기 끝에 도착하면 활성 표시가 밀기 쪽으로 넘어가므로 그때부터 밀기를 이어 간다.

득점선에 도착하기 전 성급하게 방향을 바꾸거나, 도착한 뒤에도 같은 방향을 고집하면 점수를 잃는다. 플레이어는 매 선택마다 반대로 누르는 것이 아니라 적정 범위의 양쪽 끝을 왕복해야 한다.

### 상대의 실제 대사

콤보만 보면 활성 득점선 방향의 행동을 이어 가는 것이 이득이지만, 상대가 명시적으로 요청하거나 거절했을 때는 `literal`이 나타난다.

플레이어는 높은 콤보를 포기하고 말을 그대로 들을지, 한도윤의 밀당 해석을 따라 점수를 이어 갈지 선택한다.

### 사건 마감

기다리면 다음 반응을 볼 수 있지만 사건이 지나갈 수도 있다. 마감은 별도 수치가 아니라 `오늘이 아니면 출장 전에는 어렵다` 같은 대사와 일정으로 전달한다.

## 밀기와 당기기의 결과

### 다가가기

- 현재 장면이 길어지고 즉시 반응을 본다.
- 리듬 표시점을 당기기 방향으로 `8~16` 이동시킨다.
- 당기기 득점선이 활성화되어 있고 적정 범위 안이라면 콤보와 주도권이 오른다.
- 이미 당기기 득점선을 지난 뒤라면 추가 득점 없이 적정 범위를 벗어날 위험이 커진다.

### 여백 두기

- 현재 대화를 끝내고 다음 시간대의 반응을 기다린다.
- 리듬 표시점을 밀기 방향으로 `8~16` 이동시킨다.
- 밀기 득점선이 활성화되어 있고 적정 범위 안이라면 콤보와 주도권이 오른다.
- 기다리는 동안 다른 인물과 회사의 시간도 진행된다.

### 문자 그대로 대응하기

- 상대의 요청이나 거절을 그대로 따른다.
- 콤보는 즉시 끊기고 주도권 점수를 얻지 못한다.
- 표시점은 현재 위치에서 중앙 방향으로 한 단계 이동한다.
- 속마음 모드에서 한도윤의 해석과 실제 대사의 충돌을 가장 선명하게 보여 준다.

모든 장면에 세 선택을 넣지는 않는다. 보통 `콤보를 이어 갈 선택`과 `말을 그대로 따를 선택` 두 개면 충분하다.

## 재미를 만드는 장치

### 점수 쾌감과 불길한 연출을 동시에 준다

콤보가 오를 때 숫자와 사운드는 명확하게 보상한다. 동시에 상대의 대사는 짧아지고 화면에 다른 직원이 남거나 업무 연락이 공식 채널로 이동한다.

플레이어는 처음에는 이것을 난도가 올라가는 연애 게임으로 받아들이고, 후반에는 점수 상승과 장면 분위기가 왜 반대로 움직이는지 의심하게 된다.

### 기다린 결과도 장면으로 보상한다

밀기는 아무것도 하지 않는 버튼이 아니다. 지금 물러났기 때문에 다음에 누가 어떤 이유로 움직였는지를 확인하는 선택이다.

서아가 다음 날 업무 메일을 보내면 한도윤은 콤보 성공으로 계산한다. 현실에서는 대면 접촉을 피하기 위한 공식 연락일 수 있다.

### 인물 차이는 게이지가 아니라 반응 방식으로 만든다

- 윤서아는 지연된 업무 행동으로 반응한다.
- 차민경은 즉시 말로 선을 긋고 이후 행동도 그 말과 일치한다.
- 강유진은 일부 선택에서 콤보 UI 자체를 깨뜨린다.

## 장면 예시

윤서아:

> 과장님, 메일 확인했습니다. 수정본은 내일까지 부탁드릴게요.

현재 위치는 `-24`, 활성 득점선은 당기기 `-32`, 콤보는 x2다.

선택:

1. 확인했다고 답하고 내일 수정본을 보낸다. `space`
2. 수정 방향을 지금 더 묻는다. `approach`

첫 번째 선택은 표시점을 `-12`로 되돌린다. 당기기 득점선에 도착하기 전에 방향을 바꿨으므로 콤보 점수는 없고 연속이 끊긴다. 다음 날 업무 메일이 오더라도 현실에서는 예정된 수정본에 대한 평범한 후속 업무다.

두 번째 선택은 표시점을 `-36`으로 옮겨 적정 당기기 득점선에 도착한다. 콤보 x3, 이동 점수와 턴 보너스를 받은 뒤 활성 득점선이 밀기 쪽으로 전환된다. 다음 선택에서도 당기기를 고집하면 점수를 받지 못하므로 이제 여백을 두어야 한다.

별도의 경계 장면에서 `앞으로 자료는 메일로만 보내주세요`처럼 명시적인 요청이 나오면, 그때는 요청을 그대로 따르는 `literal` 선택이 콤보를 끊는다.

## 내부 구간별 진행

아래 날짜는 사건 스케줄과 안전 불변식을 위한 제작 정보다. 플레이어 UI에는 캠페인 총일수, ACT 구분이나 타임라인 화면으로 강조하지 않는다.

### 1~5일

x1~x2 콤보를 쉽게 성공시켜 점수 상승의 쾌감을 학습시킨다.

### 6~10일

x3 콤보부터 주도권은 빠르게 오르지만 상대의 대사, 결근과 주변인의 개입이 점수와 어긋나기 시작한다.

### 11~12일

두 번째 주말의 조우와 가족·친구의 조언으로 한도윤의 성공 확신을 굳힌다. 우연처럼 보이는 장면과 일방적 추적의 현실이 처음 크게 어긋난다.

### 13~14일

비밀 사내연애와 강유진의 질투처럼 보이는 사건으로 높은 콤보를 끊지 말라고 부추긴다. 실제로 공략 대상은 사적 접촉을 피하고 유진은 사실관계만 관찰한다.

### 15일

아픈 한도윤에게 공략 대상이 물과 약, 택시를 챙기는 장면을 마지막 서비스 신처럼 연출한다. 실제로는 업무상 최소 대응이다. 이날 `betrayal` 또는 `romance` 최종 해석을 플래그로 저장한다.

### 16일

사무실 수군거림을 `사내연애가 들켰다`는 사건으로 제시한다. 공식 면담과 신고는 없고, 가족이나 친구가 회사 밖의 깜짝 고백을 조언한다.

### 17일

공략 대상의 집에 찾아간 뒤 반드시 최종 대화와 현장 신고에 도달한다. 주도권은 한도윤의 성공 확신을 결정하고, 실제 엔딩은 의심도, 비호감도, 증거, 최종 해석과 현장 행동으로 정한다.

## 내부 데이터

```text
visible.heroines.<id>.initiative
hidden.heroines.<id>.suspicion
hidden.heroines.<id>.dislike
hidden.heroines.<id>.evidence_count
```

콤보는 현재 흐름에 하나만 저장한다.

```yaml
progress:
  flags:
    push_pull:
      combo: 3
      position: -24
      target: pull
      last_action: approach
      heroine: yoon_seo_a
```

`visible.affection`과 `visible.perceived_state`는 기존 데이터 호환을 위해 당장 제거하지 않더라도 스토리 모드 UI와 신규 장면 조건에서는 사용하지 않는다.

## 제작 기준

- 콤보를 이어 갈 선택과 끊을 선택이 의미 있게 대비되는가?
- 점수 상승과 현실의 부정적 변화가 같은 장면에 함께 존재하는가?
- 기다린 선택도 다음 장면으로 보상되는가?
- 실제 거절과 경계를 사랑의 증거로 확정하지 않았는가?
- 속마음 모드에서 `밀당 주도권`을 `통제 욕구`로 다시 읽을 수 있는가?
