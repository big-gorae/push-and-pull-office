# Love Office 거시적 마스터 체크리스트

> 이 문서는 작품과 제품 전체에서 아직 결정·구현해야 할 가장 큰 작업만 관리하는 최상위 체크리스트다. 세부 제작 항목은 [`release-readiness-checklist.md`](release-readiness-checklist.md)에서 관리한다. 아래 `P0`은 다른 모든 출시 준비보다 먼저 다룬다.

## P0. 작품 핵심 구조와 결말

- [x] 표면 공략 후보를 유은솔·차민경·신나경 세 명으로 확정한다.
- [x] 실제 최종 선택 후보를 유은솔·차민경으로 확정한다.
- [x] 신나경은 호감도와 밀당 수치 및 개별 사건을 갖지만 결정적인 최종 선택에서 제외되고 최종 공략은 불가능한 위장 공략으로 확정한다.
- [x] `밀당 주도권` 상태를 폐기하고 플레이어에게 보이는 관계 수치를 `호감도`와 `밀당 수치`로 정리한다.
- [x] 서정우가 젊은 시절에는 수려했지만 현재는 기존 원화보다 훨씬 추한 인물이라는 사실을 서사 원본에 기록한다.
- [x] 가족의 강화, 다크 심리학 책에 대한 심취, 선택적 기억 재구성, 관계망상·현실 검증 저하가 함께 작동한다는 인과를 서사 원본에 기록한다.
- [ ] 신나경의 위장 공략용 주요 사건, 속마음 대화와 호감도·밀당 축적 과정을 집필하고 구현한다.
- [x] 신나경 전용 호감도 상한을 80으로 정하고, 실제 증가분 제한·기존 저장 보정·비노출 연출을 구현한다.
- [ ] 최종 후보 선택 로직을 유은솔·차민경으로 한정하고 신나경을 결정적인 선택지에서 배제한다.
- [ ] 서정우의 고백 장면과 유은솔·차민경·신나경 세 사람의 최종 반응을 집필한다.
- [ ] 서정우 결말의 정확한 분기표를 확정하고 `도주 중 사망`, `체포`, `자살`을 모두 포함한다.
- [ ] 범죄의 최종선을 넘는 분기와 위 세 결말의 관계를 확정한다.
- [ ] 서정우 현재 원화를 기존 이미지보다 훨씬 추한 최종 디자인으로 다시 제작하고 객관적 얼굴 공개 장면과 일치시킨다.
- [ ] 다크 심리학 책을 집어 들고 믿게 되는 인과 장면을 집필한다.
- [ ] 13~17일차의 회피, 밀당 반격 오독, 고백 준비와 파국을 요약 사건이 아닌 실제 플레이 장면으로 완성한다.

## P1. 작품 완성 범위

- [ ] 스토리 모드 전체 주차, 세 후보의 주요 사건과 모든 엔딩을 완성한다.
- [ ] 최초 공개 버전의 루트 수, 엔딩 수, 목표 플레이타임과 공개 범위를 확정한다.
- [ ] `어나더 스토리`의 플레이어 역할, 캠페인 범위와 1.0 포함 여부를 확정하고 구현한다.
- [ ] 작품의 콘텐츠 경고, 이용 연령, 민감 소재 표현 수위를 확정한다.

## P2. 비주얼·사운드·제품 완성

- [ ] 최종 비주얼 바이블을 확정하고 캐릭터 원화·표정·의상·배경·CG를 모두 제작 및 연결한다.
- [ ] BGM, 효과음, 음량 정책과 크레딧을 확정하고 전 구간을 검수한다.
- [ ] 저장·불러오기, 엔딩 회수, 해금, 다국어와 접근성 흐름을 출시 수준으로 검증한다.
- [ ] 데스크톱·웹·지원 모바일 범위에서 전체 루트 회귀 테스트와 성능·배포 검증을 완료한다.

## P3. 출시 결정

- [ ] 첫 공개 형태와 소비자 플랫폼을 확정한다.
- [ ] 출시 언어, 스토어 소개, 가격·배포·지원 정책을 확정한다.
- [ ] 릴리스 후보 판정 기준을 통과한 정확한 빌드를 배포하고 배포 후 스모크 테스트를 완료한다.
