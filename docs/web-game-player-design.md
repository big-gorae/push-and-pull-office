# 웹 미연시 플레이어 설계

## 결정

현재 React + TypeScript + Vite 스택을 유지한다. Phaser/Pixi는 맵, 충돌, 다수 스프라이트처럼 캔버스 장면 관리가 필요해질 때만 선택적으로 추가한다. 현재 게임의 핵심은 정지 일러스트, 대사, 선택지, 상태 분기이므로 DOM 기반 UI가 구현과 에이전트 수정 양쪽에서 가장 단순하다.

편집기와 플레이어는 같은 저장소와 스토리 런타임을 공유하되 진입점을 분리한다.

다국어 레지스트리, 장면 진입 조건, 상황별 대사 variant와 locale 독립 세이브는
[`localization-context-dialogue-redesign.md`](localization-context-dialogue-redesign.md)의
계약을 따른다. 이 문서의 기존 문자열 캐시와 고정 locale 설명보다 해당 재설계가
우선한다.

- 편집기: `/`
- 웹 플레이어: `/play` 또는 `#/play`
- 이야기 원본: `story/`
- 생성 데이터: `build/story-runtime.json`
- 플레이어 실행기: `src/player/`

정적 호스팅에서는 `sites-worker/index.js`가 `/play` 같은 SPA 경로를 `index.html`로 되돌린다. `npm run build:site`는 `VITE_APP_SURFACE=game`으로 빌드해 배포 주소의 루트도 곧바로 게임을 열며, 일반 Vite 산출물과 호스팅 진입점을 함께 준비한다.

## 일반 미연시 UI/UX에서 채택한 구조

1. 타이틀: 이어하기, 새 게임, 불러오기, 환경설정
2. 회차 시작: 첫 회차의 스토리 모드와 클리어 후 해금되는 원문 모드를 같은 자리에서 선택
3. 타임라인: 17일 날짜 진행, 고정 사건 요약, 선택 가능한 사건과 자연어 마감 표시
4. 게임 화면: 전체 장면 위에 상단 HUD, 하단 메시지 창, 중앙 선택지
5. 퀵 메뉴: 백로그, 오토, 읽은 문장 스킵, 저장, 불러오기, 설정, 창 숨기기
6. 입력: 클릭·Enter·Space로 진행, 숫자 키로 선택, 방향키로 선택지 이동, Escape/H로 UI 숨기기, PageUp·휠 올리기로 백로그
7. 저장: 자동 저장 1개와 수동 슬롯 8개를 브라우저 `localStorage`에 보관
8. 접근성: 키보드 포커스, 텍스트로 병기된 게이지 상태, 움직임 줄이기, 모바일 적응형 배치

## 이 게임에 맞춘 변형

- 호감도 하트 대신 `밀당 주도권`, `COMBO`, `당기기 ↔ 밀기` 리듬만 상시 노출한다.
- 실제 보기에서는 같은 값과 같은 배치를 `통제 욕구`, `통제 시도 연쇄`, `접근 시도 ↔ 거리 둠`으로 다시 읽는다.
- 선택지에는 계산값이나 메타 태그를 표시하지 않고 플레이어가 실제로 할 행동만 표시한다.
- 선택 직후 다음 인물 반응을 먼저 보여 주고, 밀당 결과 피드백은 짧게 지연해 표시한다.
- 백로그에는 들은 대사, 선택한 행동, 그때의 한도윤 해석을 묶어 저장한다.
- 다른 인물 사건을 선택하면 현재 콤보가 바뀔 수 있다는 사실을 확인창 대신 흐려진 카드와 한 줄 안내로 예고한다.

## 17일 타임라인 플레이 루프

웹 플레이어는 `campaigns.main`의 날짜와 시간대를 사용한다. 매 시간대를 전부 클릭하게 하지 않고, 고정 사건·보이는 마감·플레이어 선택이 있는 다음 의미 있는 순간으로 자동 이동한다.

1. 현재 날짜보다 마감이 지난 사건을 `missed`와 `expired`로 이동하고 `on_missed` 효과를 적용한다.
2. `automatic`과 `hidden` 사건을 우선순위와 `exclusive_group` 기준으로 처리한다.
3. 스토리 모드에서는 숨은 사건을 표시하지 않고, 원문 모드에서 같은 시간선에 복원한다.
4. 조건을 만족한 `player` 사건만 카드로 표시한다.
5. 사건을 선택하면 `on_seen` 효과를 먼저 적용하고 연결 장면을 시작한다.
6. `return_to_timeline` 장면은 종료 뒤 현재 시간대로 복귀한다. `honor_scene_exit`은 장면의 엔딩 분기를 따른다.
7. 엔딩에 도착하면 클리어 루트와 해금 모드를 회차 프로필에 합친다.

## 일러스트 호흡 연출

기본 연출은 GIF나 리깅 없이 정지 이미지 전체에 매우 작은 세로 스케일과 위치 변화를 약 5.8초 주기로 적용한다. 움직임 줄이기를 켜면 정지한다.

이 방식은 가볍고 모든 PNG/WebP에 바로 적용할 수 있지만, 머리카락·눈·입·가슴을 서로 다르게 움직이지는 못한다. 그런 부분별 움직임이 필요해질 때만 별도 레이어 PSD/PNG 또는 Live2D 모델을 추가하고, 플레이어의 `Stage` 렌더러를 교체한다. 스토리 데이터와 저장 시스템은 그대로 유지한다.

## 런타임 흐름

`dual_dialogue`와 `dual_narration`은 메시지 창에서 재생한다. `choice`는 조건을 통과한 선택지만 표시한다. `effect`와 `state_gate`는 화면 없이 자동 처리한다. `exit`은 조건에 맞는 다음 장면이나 엔딩으로 이동한다. 선택 시 기존 `resolvePushPull` 계산을 그대로 호출하므로 편집기 미리보기와 웹 게임의 결과가 달라지지 않는다.

`src/player/playerRuntime.test.ts`는 의미 있는 시간대로의 이동, 선택 사건의 일정 복귀, 마감 실패, 엔딩 우선순위, 클리어 후 모드 해금을 실제 생성 런타임으로 검증한다.
