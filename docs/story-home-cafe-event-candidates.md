# 홈카페·소형 주방가전 사건 후보 뱅크

> 상태: 아이디어 후보. 이 문서만으로는 구현된 사건이나 확정 시간선이 아니다.

다원리빙의 회사 장면을 새로 구상할 때 먼저 검토하는 소재 목록이다. 실제 채택 시에는 `story/world/`의 회사·프로젝트 책임과 모순되지 않게 구체화하고, `story/events/`와 `story/scenes/`에 연결한 뒤 모든 검증을 통과시킨다.

## 고정 업무 분업

- 한도윤: 백화점·편집숍 바이어, 입점 조건과 승인 일정
- 윤서아: 제품 사양표, 회의 자료, 대여 샘플과 목록
- 차민경: 프로젝트 마스터 일정, 인플루언서·크리에이터 실무 연락과 공개 일정
- 강유진: 패키지·촬영물 제작, 콘텐츠 버전과 제품 문구 사실 검수
- 텍스트 전용 동료: 두 핵심 팀의 주임·차장·부장을 회의 진행, 자료 확인과 일상 대화에 우선 활용

민경은 협업 상대에게 브리프를 전달하고 수정 요청을 정리하며 공개 가능 시점을 확정하는 대외 창구다. 유진은 전달할 파일과 제품 정보가 실제 승인본과 일치하는지 확인한다. 두 사람의 역할을 합쳐 쓰지 않는다.

| `sample_delivery_mixup` | 인플루언서 대여 샘플이 다른 직원 자리나 다른 협업처 상자로 섞인다. | 일상 대화형 사건으로 쓰기 좋다. 송장·제품 번호·수령 기록을 확인하며 여러 팀원이 자연스럽게 짧게 말한다. | 서아·정주임·민경 / 오픈 오피스·택배 보관대 |

## 가벼운 일상 후보

- 사내 홈카페 시음 투표: 커피메이커 추출 설정을 비교하며 동료별 말투와 업무 취향을 보여 준다.
- 제품 이름 회의: 후보 이름이 너무 감성적이거나 기능을 오해하게 만들어 서아·민경·유진이 서로 다른 기준으로 수정한다.
- 라이브커머스 리허설: 큐시트와 제품 동작 순서가 어긋나 민경이 진행자와 순서를 맞추고 유진이 화면에 잡히는 승인본을 확인한다.
- 샘플 정리 날: 책상과 창고에 흩어진 박스·라벨·부속품을 정리하며 텍스트 전용 동료가 짧게 끼어드는 일상 대화를 만든다.

## 채택 원칙

1. 사건의 객관적 문제는 `perceived`와 `reality`에서 동일하게 유지하고, 차이는 한도윤의 의미 부여에서 만든다.
2. 업무 사고를 특정 히로인의 무능으로 고정하지 않는다. 역할 분담, 기록과 복구 선택이 인물 차이를 보여 주게 한다.
3. 야간 설치·출장·촬영도 자동으로 둘만의 로맨스 공간이나 경계 침범 사건이 되지 않는다.
4. 평범한 업무 지원 자체에는 의심도·비호감도·증거 증가를 붙이지 않는다. 숨은 결과는 반복 접촉, 권한 사용이나 명시적 경계 침범에만 연결한다.
5. 회의와 일상 대화에는 영업기획팀·브랜드마케팅팀의 텍스트 전용 동료를 우선 넣고, 새 팀이나 외부 고정 조연은 꼭 필요할 때만 추가한다.
6. 안전 민원은 피해나 대응 절차를 중심으로 쓰고 위험을 재현하거나 악용할 수 있는 세부 조작법은 적지 않는다.
