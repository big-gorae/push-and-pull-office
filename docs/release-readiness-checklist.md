> 기준일: 2026-08-12
> 목적: 스토리뿐 아니라 캐릭터 원화, 배경, 보상 일러스트, 사운드, 게임 시스템, 생존편, 제작 도구, QA와 배포를 포함한 제품 전체의 출시 준비 상태를 관리한다.

## 1. 핵심 비주얼 방향과 캐릭터 원화

### 1.1 공통 비주얼 바이블

- [ ] 최종 그림체, 채색 밀도, 선 굵기, 얼굴 비율, 광원과 색감 기준을 한 문서로 잠근다.
- [ ] 캐릭터 간 키, 체형, 얼굴 크기와 카메라 거리의 상대 기준표를 만든다.
- [ ] 16:9 게임 화면의 좌·중·우 배치와 안전 영역을 확정한다.
- [ ] 원화의 기준 해상도, 투명 여백, 발끝/허리/가슴상 구도와 파일 형식을 확정한다.
- [x] 원본 보존과 비파괴 누끼 파이프라인이 있다.
- [ ] 모든 최종 원화에 동일한 누끼 품질, RGB 보존, 가장자리와 반투명 머리카락 QA를 수행한다.
- [ ] AI 생성 원화의 프롬프트, seed, reference, 수정 이력과 최종 채택 이유를 보존한다.
- [ ] 임시 콘셉트 아트와 실제 런타임 원화를 자산 목록에서 명확히 구분한다.

### 1.2 캐릭터별 최종 디자인

- [ ] 한도윤 최종 디자인을 잠근다.
- [ ] 윤서아 최종 디자인을 잠근다.
- [ ] 차민경 최종 디자인을 잠근다.
- [ ] 강유진 최종 디자인을 잠근다.
- [ ] 임수연 최종 디자인을 잠근다.
- [ ] 어둠의 심리학 강사 최종 디자인과 필수 원화 구성을 잠근다.
- [ ] 생존편 신규 주인공·조연이 있다면 최종 디자인을 잠근다.
- [ ] 같은 인물이 모든 원화와 CG에서 눈, 얼굴형, 점, 머리색, 헤어스타일과 체형을 유지하는지 비교표로 검수한다.

### 1.3 상황별 의상과 기본 원화 매트릭스

각 캐릭터에 대해 실제 등장 상황을 기준으로 `필요 / 제작 중 / 승인 / 런타임 연결` 상태를 기록한다.

- [ ] 사무실 기본 복장
- [ ] 회의·프레젠테이션 복장 또는 재킷 상태
- [ ] 회식·퇴근 후 복장
- [ ] 오피스텔·귀가 상황의 생활복
- [ ] 토요일 외출복
- [ ] 일요일 외출복
- [ ] 출장·외근 상황 복장
- [ ] 위기·엔딩 상황의 복장과 흐트러짐
- [ ] 생존편 전용 복장
- [ ] 필요한 경우 계절·날씨 변형
- [ ] 각 의상별 정면 기본 자세
- [ ] 각 의상별 대화용 좌·중·우 배치 품질
- [ ] 각 의상별 썸네일과 에디터 자산 카탈로그 등록
- [ ] 사용하지 않는 임시 원화는 런타임 목록에서 제외하되 제작 원본은 보존

### 1.4 표정·포즈 세트

- [ ] 각 캐릭터의 `평상`, `업무 집중`, `기쁨`, `당황`, `불편`, `경계`, `분노`, `피로`, `체념` 필요 여부를 장면별로 결정한다.
- [ ] perceived 전용 과장 표정과 reality 실제 표정을 혼동하지 않게 분리한다.
- [ ] 표정 이름과 실제 이미지가 캐릭터 YAML의 의미와 일치한다.
- [ ] 말하는 인물뿐 아니라 듣는 인물의 필요한 포즈를 준비한다.
- [ ] 팔짱, 휴대전화, 서류, 컵, 가방 등 반복 소품이 필요한 포즈를 확정한다.
- [ ] 모든 사용 표정이 캐릭터 정의와 비주얼 자산에 등록되어 있다.
- [ ] 존재하지만 한 번도 사용하지 않는 표정과 필요한데 없는 표정을 자동 보고한다.
- [x] 한도윤 일반 원화 비노출과 엔딩 공개 정책이 기계적으로 검증된다.

## 2. 배경과 장면 미술

- [ ] 전체 사건을 `장소 × 시간대 × 분위기 × perceived/reality` 배경 매트릭스로 정리한다.
- [ ] 1주차 모든 장면의 최종 배경을 승인한다.
- [ ] 2~3주차 모든 장면의 최종 배경을 승인한다.
- [ ] 생존편 모든 장면의 최종 배경을 승인한다.
- [ ] 다음 핵심 장소의 필요 변형을 확정한다.
  - [ ] 오픈 오피스
  - [ ] 회의실
  - [ ] 복도·탕비실·휴게 공간
  - [ ] 외근·거래처·쇼룸
  - [ ] 회식 장소
  - [ ] 카페·서점·전시·팝업 등 주말 장소
  - [ ] 오피스텔 로비·엘리베이터·복도·현관
  - [ ] 한도윤의 집과 밤 활동 공간
  - [ ] 인사팀·조사·경찰·엔딩 장소
- [ ] 같은 배경의 아침·낮·저녁·밤 변형이 단순 색 필터로 충분한지 장면별로 판단한다.
- [ ] romance insert와 위기 장면의 특수 연출이 배경을 과도하게 가리지 않는지 검수한다.
- [x] 위치·시간·분위기 기반 배경 자동 판정과 scene override 기반이 있다.
- [ ] 임시 `outside_cafe`, `office_break_room` 같은 범용 배경 사용을 최종 장면별 배경으로 교체한다.
- [ ] 모든 배경의 원근, 캐릭터 발 위치, UI 가림 영역과 모바일 크롭을 확인한다.
- [ ] 배경 원본·생성 이력·런타임 최적화본을 분리 보존한다.

## 5. 밀당·선택·성장 시스템 확정

### 5.1 밀당 핵심 규칙

- [x] 위치, 다음 득점 방향, 점수와 콤보의 기본 계산이 구현되어 있다.
- [x] `interaction.target`과 `push_pull.target`이 분리되어 있다.
- [x] 지원 화법 메타데이터가 숨은 수치나 밀당 점수를 자동 변경하지 않는다.
- [ ] 시작 위치, 이동량, 적정 범위 폭, 득점량과 콤보 규칙을 최종 밸런스로 잠근다.
- [ ] 서아·민경의 리듬 차이를 실제 플레이에서 구분 가능하게 만든다.

- [ ] 밀당 점수와 실제 호감·동의·안전을 혼동하지 않는 서사 계약을 전 장면에서 지킨다.
- [ ] 엔딩 조건에 밀당·의심·비호감·증거가 각각 어떤 역할을 하는지 최종 확정한다.

## 13. 지금 집중할 순서

1. 출시 범위, 생존편 포함 여부와 밀당 시스템의 최종 규칙을 결정한다.
