# push-and-pull-office

작품의 메인 소재·로그라인·주제·시놉시스는 [`docs/story-planning-overview.md`](docs/story-planning-overview.md), 최상위 미결 작업은 [`docs/master-checklist.md`](docs/master-checklist.md)에서 관리합니다.

## 웹 플레이어 실행

최초 한 번 의존성을 설치한 뒤 개발 서버를 실행합니다.

```bash
npm install
npm run dev
```

브라우저에서 `http://127.0.0.1:1420`에 접속합니다.

## 자동 검증

로컬과 GitHub CI는 같은 단일 명령으로 스토리 계약, 모든 선택 분기,
생성물 일치, 플레이어 테스트, 배포 빌드와 실제 브라우저 계약을 검사합니다.

```bash
npm run verify
```

`npm install`은 저장소의 버전 관리된 pre-push hook도 활성화합니다. 원격 `main`은
필수 CI가 성공한 자동 PR만 병합되도록 보호합니다.

## 스토리 상태 에디터

YAML을 빌드한 뒤 수치에 따른 표정, 대사, 선택지와 분기를 브라우저에서 확인합니다.

```bash
make story-editor
```

브라우저가 자동으로 열리지 않으면 `http://127.0.0.1:8765/editor/`에 접속합니다.

## Tauri 스토리 제작 에디터

캠페인의 내부 일정에 사건을 배치하고, 연결된 장면·단일 대사 노드를 편집합니다. 전체 검증을 통과한 YAML만 안전하게 저장합니다. 플레이어 화면에는 이 제작용 일정표나 ACT 구분을 노출하지 않습니다.

```bash
make editor-setup
make tauri-dev
```

`make tauri-dev`는 이미 실행 중인 제작 버전을 재사용하고, 중복 실행과 1420 포트 충돌을 확인합니다. 스토리 에디터가 열린 뒤 실제 제작 플레이는 `▶ 게임에서 대사 편집` 버튼으로 엽니다.

첫 설정은 프로젝트 내부 `.tooling/`에 Rust를 설치하고 `.venv/`와 npm 패키지를 준비합니다. 시스템의 다른 Rust·Python 프로젝트 설정은 바꾸지 않습니다.

주요 기능:

- 캠페인 시간대 타임보드와 인물별 스윔레인
- 고정 사건, 선택 사건, 보이지 않는 사건과 마감 처리
- 현재 수치에서 사건이 열리거나 막히는 이유 표시
- 시간대 실행, 놓친 사건 처리와 오프스크린 사건 시뮬레이션
- 단일 시간선의 사건·장면 연결과 클리어 후 추가 콘텐츠
- 시간 이벤트의 조건·효과·우선순위·발생 기간 GUI 편집
- 발생 방식·소요 시간·장소·참여 인물·연결 장면·독점 그룹·놓침 연쇄 사건 GUI 편집
- 전체 날짜·시간대·내부 구간·사건 레인과 스레드 순서 GUI 편집
- 루트의 해금 조건·스토리 모드 순서·시작 장면·엔딩 구조 GUI 편집
- 클리어 후 모드 해금과 다음 이야기 예고 GUI 편집
- 6종 노드의 구조화된 편집
- 기존 장면을 연결 일정·루트·스레드와 함께 안전하게 복제하고 즉시 편집
- 기존 시간 사건을 소속 스레드 순서와 함께 안전하게 복제
- `인물 / 수치 / 비교 / 값` 형태의 조건 빌더
- 인물 프로필·불변 사실·말투·외형·표정·감정 행동 규칙·신고 규칙·관계 편집
- 선택지 효과와 상태 계약 자동 계산
- 스토리 모드 단일 대사 라이브 미리보기
- 한국어·영어 런타임 문자열 카탈로그, 번역 누락률과 기본 언어 fallback
- 시간·장소·분위기에 따라 자동 선택되는 5종 배경 일러스트
- 배경·캐릭터 원형을 상속하고 의상·포즈·표정을 조합하는 비주얼 객체 모델
- 배경 판정 조건·우선순위와 인물 의상·자세·이미지 자산 GUI 편집
- `연출·번역` 작업 공간의 16:9 무대 프리뷰와 객체 해석 근거
- Undo/Redo와 미저장 초안 복구
- 입력을 멈추면 약 1초 뒤 검증을 통과한 내용을 YAML과 런타임에 자동 저장
- 장면·이벤트·인물·번역·프로젝트 설정 초안의 종료 전 복구 보관과 작업 공간 전환 중 저장 유지
- 외부 파일 변경 충돌 감지
- 주석과 키 순서를 보존하는 원자적 YAML 저장
- 여러 YAML을 만드는 복제 작업의 사전 복사 검증과 전체 롤백
- `⌘P` 장면·사건·인물·캠페인·루트·스레드·해금·비주얼 통합 검색, `⌘S` 즉시 저장, `⌘Z`/`⇧⌘Z` 실행 취소·다시 실행
- 현재 편집 중인 YAML의 절대 경로와 Finder 바로가기

시간표 판정만 터미널에서 확인할 수도 있습니다.

```bash
python3 tools/story_harness.py timeline --day 5 --slot after_work --process-automatic
```

macOS 앱 빌드:

```bash
make tauri-build
```

완성된 앱은 `src-tauri/target/release/bundle/macos/밀당 오피스 스토리 에디터.app`에 생성됩니다.

[`docs/system/tauri-story-editor-design.md`](docs/system/tauri-story-editor-design.md)에 정리되어 있습니다.
